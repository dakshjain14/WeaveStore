WeaveStore

GitHub

Store any file as a weaving draft (.wif). The draft opens in normal weaving software and could be woven on a real loom. Load it back in here to get your file out.

How it works

    
    
      
  • The cloth is split into 4x4 blocks of over/under.
    • 
      
  • Only blocks with no run longer than 2 are used (2030 of them), so no thread floats over more than 4 others.
    • 
      
  • 3 blocks hold 4 bytes, about 1.33 bytes per pick on 16 shafts.
    • 
      
  • The file is stored in the liftplan itself. Nothing is hidden in the notes.
