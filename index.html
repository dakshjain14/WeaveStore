Store a file in a piece of cloth

WeaveStore turns a file into a weaving draft (.wif), the format weavers use to share patterns. The draft opens in weaving software and could be woven on a real loom. Load it back in here and you get the exact same file out, checked against its SHA-256.

1File to draft

Any type of file works. Size is the catch, see limits.

What's a shaft?

On a loom, every lengthways thread (the warp) runs through one shaft. Lifting a shaft lifts all of its threads, and the crossways thread (the weft) passes under them. So the shaft count is how many groups of threads you can move on their own for each row. More shafts means more data per row, but a bigger loom. Most hobby looms have 4 or 8. 16 and 24 usually mean a dobby loom, often computer controlled.

Pick what your loom has, or leave it on 16 if you're just trying it out. The draft remembers its shaft count, so you don't set it when reading back.

Limits

    
The file type doesn't matter: photos, zips, PDFs and empty files all come back byte for byte. What limits you is size, because each pick (one pass of the weft) only holds a byte or two.

How it works

    
    
      
  1. The file gets a small header (name, length, part of its SHA-256), and is compressed if that makes it smaller.
    2. 
      
  2. The cloth is split into 4×4 blocks of over and under. Of the 65,536 possible blocks, only the 2,030 with no row or column running more than 2 the same are used.
    3. 
      
  3. That rule means no thread ever floats over more than 4 others, so the cloth holds together. Every draft is checked for it.
    4. 
      
  4. 3 blocks hold 4 bytes. Blocks go side by side across the shafts, then row by row down the cloth.
    5. 
      
  5. The pattern lives in the liftplan, the part of the draft that says which shafts go up on each pick. Nothing is hidden in notes or comments.
    6. 
      
  6. Reading it back rebuilds the cloth, turns the blocks back into bytes, and checks the hash.
    7. 
    


    
Words

    

      
Warp
The threads running lengthways, set up on the loom first.

      
Weft
The thread going across, over and under the warp.

      
Pick
One pass of the weft. One row of the draft.

      
Shaft
A frame that lifts a group of warp threads together.

      
Float
A thread skipping over several others. Long floats snag, so they're kept to 4.

      
Liftplan
Which shafts go up on each pick. This is where the file is stored.
